## Convención de commits (técnicos y descriptivos)
- `feat(auth): agrega pantalla de login con validación de correo y contraseña`
- `feat(data): implementa repositorio DataStore para registros y citas`
- `feat(agenda): valida choque de horarios al confirmar cita`
- `test(validacion): agrega pruebas unitarias de Validadores`
- `docs: completa README con integrantes y pasos de ejecución`

## Reglas
- Un commit por cambio lógico, ramas `feature/*` y Pull Request revisado por el otro integrante.
- No hacer ningún commit después de la fecha de entrega y antes de la evaluación.
